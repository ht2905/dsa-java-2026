Problem Statement

The Kingdom of Takahashi is made up of NNN towns and N−1N-1N−1 roads, where the towns are numbered 111 through NNN. The iii-th road (1≤i≤N−1)(1 \leq i \leq N-1)(1≤i≤N−1) connects Town aia_iai​ and Town bib_ibi​, so that you can get from every town to every town by using some roads. All the roads have the same length.

You will be given QQQ queries. In the iii-th query (1≤i≤Q)(1 \leq i \leq Q)(1≤i≤Q), given integers cic_ici​ and did_idi​, solve the following problem:

  • Takahashi is now at Town cic_ici​ and Aoki is now at Town did_idi​. They will leave the towns simultaneously and start traveling at the same speed, Takahashi heading to Town did_idi​ and Aoki heading to Town cic_ici​. Determine whether they will meet at a town or halfway along a road. Here, assume that both of them travel along the shortest paths, and the time it takes to pass towns is negligible.

Constraints

  • 2≤N≤1052 \leq N \leq 10^52≤N≤105
  • 1≤Q≤1051 \leq Q \leq 10^51≤Q≤105
  • 1≤ai<bi≤N (1≤i≤N−1)1 \leq a_i < b_i \leq N\, (1 \leq i \leq N-1)1≤ai​<bi​≤N(1≤i≤N−1)
  • 1≤ci<di≤N (1≤i≤Q)1 \leq c_i < d_i \leq N\, (1 \leq i \leq Q)1≤ci​<di​≤N(1≤i≤Q)
  • All values in input are integers.
  • It is possible to get from every town to every town by using some roads.

Input

Input is given from Standard Input in the following format:

NNN QQQ
a1a_1a1​ b1b_1b1​
a2a_2a2​ b2b_2b2​
⋮\hspace{0.6cm}\vdots⋮
aN−1a_{N-1}aN−1​ bN−1b_{N-1}bN−1​

c2c_2c2​ d2d_2d2​
⋮\hspace{0.6cm}\vdots⋮
cQc_QcQ​ dQd_QdQ​

Output

Print QQQ lines. The iii-th line (1≤i≤Q)(1 \leq i \leq Q)(1≤i≤Q) should contain Town if Takahashi and Aoki will meet at a town in the iii-th query, and Road if they meet halfway along a road in that query.
